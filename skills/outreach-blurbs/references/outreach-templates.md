# Outreach templates

Plain, warm, specific. No "I hope this finds you well", no flattery about the company, no buzzword stacks. Use one
proof point per message, with its number, taken from the inventory. Every message ends with one small ask.

## Types

| Type | Limit | Shape |
|---|---|---|
| **LinkedIn connection note** | 300 characters including spaces | Role name + one proof point + ask to connect or chat |
| **Recruiter email / InMail** | Under 120 words | Subject line; 3 short sentences: why this role, best proof, ask for 15 minutes or a next step |
| **Hiring-manager email / InMail** | Under 120 words | Subject line; lead with the team's problem (from the posting's top outcome), then the proof that matches it, then the ask. More about their work, less about the candidate's resume |
| **Referral ask** | Under 100 words | Name the person's connection to the company, the role, one proof point, and make it easy: "happy to send a blurb you can forward" |
| **Follow-up** (about 7 days after applying or messaging) | Under 60 words | Reference the earlier message, add one new fact (a relevant result or a shipped project), repeat the ask |

Recruiters scan for fit to a requisition; hiring managers care about the problem the role solves. Write them
differently, don't just swap the greeting.

## Closed or stale postings

If the posting looks closed, replace the role-specific ask with: "Is this or a similar role still open?" Keep the
proof point.

## Rules

- Sign off with the candidate's name and, if `profile.json` has one, their LinkedIn.
- Never invent a name, a shared connection, a referral, or something the person said.
- Don't name a client or an employer's confidential project; use the inventory's approved wording.
- Put the ask in the last sentence. Offer two time windows only if the user supplied their availability.

## `Outreach.md` layout

```
# <Company> — <Role>: outreach
**Posting status:** open / possibly closed (date posted)   **Proof point used:** <inventory bullet, with number>

## LinkedIn connection note (<n>/300 characters)
...

## Recruiter email / InMail
Subject: ...
...

## Hiring-manager email / InMail
Subject: ...
...

## Referral ask   (only if requested)
## Follow-up      (only if requested)
```
